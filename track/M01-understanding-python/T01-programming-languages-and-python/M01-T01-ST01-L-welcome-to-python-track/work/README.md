#Programming vs Programming Language

## What Is Programming?

Programming is a set of instructions to solve a problem.

## What Is a Programming Language?

Formal set of instructions to communicate with the computer

## What Is Python?

Python is a high level, hybrid, platform independent programming language.

## What is Syntax?

Synatx is the writing rules of a programming language.

## Programming and Python

Programming is a set of instructions to solve a problem. Python is a high level programming language.

## What Remained the Same?

Both pseudocode and Python are human readable and understandable.

## What Changed?

When pseudocode is converted into Python, informal human-readable instructions are replaced with strict, standardized syntax and exact built-in functions so a computer can execute the code.
